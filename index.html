生存链路：撸树得原木 → 木板 → 木棍 → 工作台 → 木镐 → 挖石头得圆石 → 石镐 → 挖铁矿 → 熔炉烧成铁锭 → 铁镐 → 挖钻石矿 → 钻石镐。
石头一类方块必须用镐才掉落；铁矿要石镐以上，金矿/钻石矿要铁镐以上。镐越好，挖得越快。
生存：疾跑和跳跃会消耗饥饿，饥饿掉光会持续掉血；饥饿满时会自动回血。摔落超过 3 格、水里憋气超过 15 秒都会扣血。
砍橡树树叶有几率掉苹果，拿着苹果右键吃掉可以回饥饿（开局送 3 个）。血量归零会死亡，回出生点重生。
生物：白天刷猪牛羊鸡（打一下会掉生肉，羊毛/皮革能捡），晚上刷僵尸、骷髅、苦力怕。左键可以打生物，手上拿镐/斧/铲伤害更高（斧最高）。
生肉丢进熔炉加燃料能烧成熟肉，回的饥饿多得多；腐肉也能吃，但回得少。僵尸和骷髅白天在太阳下会自燃。
